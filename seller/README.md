# FranLuz Seller Android v1.0.0

Aplicativo Android separado para o Seller Center da FranLuz Home Decor.

- App: FranLuz Seller
- Application ID: com.franluz.seller
- Seller Center: https://franluzhomedecor.infinityfree.io/seller-franluz/
- Compile SDK: 36
- Target SDK: 36
- Min SDK: 26

A v1.0 abre diretamente o Seller Center, preserva sessão/cookies do WordPress, suporta upload nativo de foto/vídeo, integra o botão Voltar do Android, abre links externos no app correto e possui tela offline própria.

A assinatura debug é somente para testes. A distribuição definitiva deve usar uma chave de produção própria e permanente para com.franluz.seller.
